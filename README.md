A star-garden survival story: a small light against the long night. Your past is a weapon — the echo dash plants a wake of light that damages what crosses it. Survive escalating waves of night-born foes, meet the Watcher, and bring the dawn home.

Original browser game, plain ES modules, canvas 2D, WebAudio-generated sound, fixed-timestep simulation, offline, no network requests, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

WASD/arrows move · Space/click fire · Shift echo dash · P pause · M sound
